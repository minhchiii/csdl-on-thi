# Ôn thi Lý thuyết Cơ sở dữ liệu

Trang web ôn tập tương tác học phần **Lý thuyết Cơ sở dữ liệu** (chạy tĩnh hoàn toàn, hỗ trợ offline và GitHub Pages):

- **Tóm tắt & Công thức**: 4 chương từ slide bài giảng, sơ đồ ER/EER chuẩn Chen (SVG), bảng quy tắc và Ma trận đề 2023.
- **Flashcard**: 210 thẻ ghi nhớ khái niệm, công thức và ví dụ.
- **Luyện tập & Thi thử trắc nghiệm**: 572 câu từ 13 bộ đề/bài tập (chấm ngay kèm lời giải chi tiết, thi thử tính giờ 60 phút / 50 câu, lọc ẩn câu trùng / câu thiếu dữ liệu, ôn lại câu làm sai).
- **Tự luận ER/EER, Đại số quan hệ & Chuẩn hóa**: 23 bài tập tự luận kèm sơ đồ lời giải từng bước.
- **Tiện ích**: Bảng tra nhanh Cheat sheet, Dark/Light mode, lưu tiến độ `localStorage`, Import/Export JSON.

## Kiểm tra dữ liệu cục bộ

```bash
node tools/validate.js
node tools/check-dups.js
```
